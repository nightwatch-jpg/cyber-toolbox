# 🛡️ Cyber Toolbox

My first cybersecurity tool, written in Python. 

## 🚀 Features:
1. **Port Scanner** — checks for open ports on an IP address (uses multithreading for speed).
2. **Security Auditor** — checks for important security headers (HSTS) on a website.
3. **Password Check** — searches for a password in a database of popular leaks and checks its length.
